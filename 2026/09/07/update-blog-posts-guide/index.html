上一篇教了你”怎么把博客搭起来、发上线”，这篇教你怎么日常维护。
文章要怎么建？图片放哪、怎么插进文章里？首页卡片图怎么换？
目录和标签怎么加？改完怎么重新发布？
一篇讲完，都是实操，跟着做就行。

先记住一个总原则：在 Hexo 里，”写文章”和”发文章”是两回事。

  • 平时你只改一个叫 source/ 的文件夹里的文件（这就是你的”稿子”，本地）。
  • 写好了，运行一次部署命令，Hexo 才会把这些稿子转成网站，传到 GitHub 上。
  • 所以：你改稿子的地方（source）和线上看到的网站（GitHub）是分开的，改完 source 里的东西，必须”部署”一下，线上才会更新。

这点很重要，记不住没关系，下面的步骤会一直强调。

一、先弄明白文件都放在哪

打开你的博客文件夹（就是你当初 hexo init 生成的那个，比如叫 myblog），里面的关键结构是这样：

你平时打交道的主要就两个地方：

文件夹 放什么 干嘛用
source/_posts/ 文章正文（.md 文件） 每篇文章就是这里的一个文件
source/images/ 文章里用到的图片 图片集中放这儿，方便管理

themes/、public/、.deploy_git/ 这些不用管。public 是生成出来的临时网站，每次部署会被自动覆盖，别去手动改里面的东西（改了下次也会被冲掉）。

二、新建一篇文章

最简单的方式，在终端里敲一句：

命令 说明
hexo new "我的第一篇技术笔记" 在 source/_posts/ 里生成一个空的 .md 文件

或者你也可以不敲命令，直接手动在 source/_posts/ 文件夹里新建一个 xxx.md 文件，效果一样。只是文件名最好用英文或拼音，避免中文在网址里太长太乱（当然中文也能用，看你喜好）。

三、front-matter：文章的”身份证”

front-matter 里每一行控制文章的一个属性，很直白：

配置项 作用 示例
title 文章标题 title: 我的第一篇技术笔记
date 发布时间 date: 2026-09-07 13:00:00
tags 标签（可多个） tags: 下面每行一个，如 - Hexo
categories 分类 categories: 下面写 - 技术
cover 首页卡片的小图 cover: /images/xx.png
top_img 点进文章后顶部的大图 top_img: /images/xx.png

这些字段怎么填、每一项管哪块，后面会讲。

怎么加目录（TOC）

Hexo 的 Matery 主题默认自带文章目录，就是正文旁边那个会跟随滚动的小栏目。只要文章里有标题（##、### 这些），目录就会自动出现。你不需要额外写代码。

不想让某篇显示目录，就在 front-matter 里加一行 toc: false 就行。

  • top_img = 你点进去后，文章最顶部那张横贯全屏的大图。

八、常见问题

1. 改了图片/文章，但网页没变化？

先问自己：**”我部署了吗？”** 90% 是这个原因。只改了 source/ 里的文件、没运行部署命令，线上当然不变。运行 deploy.bat 就好。

另外，改了图但本地预览也不变？浏览器可能缓存了旧图，按 Ctrl + F5 强制刷新一下。

2. 首页出现两篇内容相同的文章？

多半是你手动复制了 .md 文件，或新文件内容重复了。检查 source/_posts/ 下有没有多余文件，删掉即可。

3. 图片显示不出来（破图）？

检查两点：

  • 地址对不对：本地图要以 /images/... 开头，确认文件真的放在 source/images/ 对应目录里。
  • 部署了吗：图是跟着部署一起上传的，忘了部署就看不到。

4. 我想临时藏起一篇文章，不删掉？

两种办法：

  • 在 front-matter 里加 published: false，文章就不会显示了。
  • 或者把文件移出 _posts/ 文件夹（比如放到别处备份），再部署即可。

小结

一句话总结：文章和图片放在 source/ 里，改完运行 deploy.bat 发布。

front-matter 管标题、标签、分类、封面；Markdown 管正文排版；图片用 ![]() 插入、本地图放 source/images/。剩下的就是多写、多发布，熟能生巧。
